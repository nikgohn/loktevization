Контроль - это выявление соответствия выходной величины требуемому значению или пределам значений, допуску; при этом численное значение контролируемой величины не определяется.
Результатом автоматического контроля является формирование сигнала о несоответствии текущего значения выходной величины некоторому заранее заданному значению.
Таким образом, автоматическая сигнализация - это сообщение (фиксация) результата контроля (в форме "больше/меньше", "да/нет", 0/1 и т.п.) путем включения сигнального устройства для оповещения оператора и принятия им последующего решения.

Управляющие функции АСУТП

Управляющие функции АСУТП включают в себя действия по выработке и реализации
управляющих воздействий на объект управления. Здесь под выработкой понимается определение (на основании полученной информации) рациональных воздействий, а под реализацией - действия, обеспечивающие осуществление принятых после выработки решений.

Блокирующие - защита оборудования в штатном режиме
ПАЗ - защита оборудования в аварийном режиме

По характеру технологического процесса

Характер технологического процесса определяется временным работы технологического оборудования

- с непрерывным характером производства (Process Automation);
- с периодическим (дискретным) характером производства (Factory Automation);
- со смешанным характером производства (Hybrid Automation).

Периодическое (дискретные) процессы:
- длительность технологических операций незначительна (секунды, минуты, часы)
- возникает необходимость частой смены технологических режимов, изменения маршрутов материальных и энергетических потоков
- осложняется решение вопросов автоматизации

Такие производства преобладают на шинных, машиностроительных, резинотехнических

Особенности технологических процессов, автоматизируемых с помощью ПЛК

1. Большинство входных и выходных переменных процесса представляют собой дискретные величины, принимающие значения лог. 0 или лог. 1
2. Описание таких переменных легко производить с помощью логических функций. 
3. Технологический процесс выполняется циклически, нам достаточно описать в программе один законченный цикл и предусмотреть переход к следующему.

Упрощённое представление структуры регулирования (АСР)
![[Pasted image 20250908133917.png]]

Для регулирования необходимо:
- Регулируемый параметр, значение которого мы хотим поддерживать
- Контрольно-измерительное устройство (датчик) - для контроля текущего значения регулируемого параметра
- Задатчик - для задания требуемого значения регулируемого параметра, которое мы хотим поддерживать
- Элемент сравнения - для определения ошибки регулирования
- Управляющее устройство - для выработки регулирующего воздействия
- Исполнительное устройство - рабочий орган, осуществляющий непосредственное воздействие на объект управления (регулирующее воздействие) с целью изменения регулируемого параметра по заданному закону
- Преобразовательные устройства - для преобразования вида передаваемых сигналов в системе управления

Механизация производственного процесса
- Замена мускульной энергии человека механической путём использования машин и механизмов, приводимых в движение различными двигателями (электрическими, паровыми, гидравлическими и др.)
- исключает тяжёлый физический труд при выполнении основных и вспомогательных операций
- Например, механизация процесса установки детали на станок с помощью электротельфера или поворотного крана устраняет тяжёлую работу по ручному подъёму заготовки.

![[Pasted image 20250908135212.png]]

Комплексная механизация

- применении систем машин, механизмов и других технических средств, увязанных между собой по производительности, обеспечивающих исполнение технических и других производственных операций по всему циклу производственного процесса без применения ручного труда, за исключением операций по управлению машинами и механизмами, их регулированию и наладке.
- создает условия для перехода к высшей ступени механизации — автоматизации и комплексной автоматизации производства.

Автоматизация — использование специальных технических средств, математических методов и систем управления, действующих без непосредственного участия человека в получении, преобразовании, передачи информации и без участия человека при формировании управляющего воздействия (автоматическое управление) или с небольшим участием человека (автоматизированное управление)

Основные цели автоматизации технологического процесса:

1.  Сокращение численности обслуживающего персонала.
2.  Повышение производительности труда.
3.  Увеличение объёмов выпускаемой продукции.
4.  Повышение надёжности и точности производства.
5.  Улучшение качества продукции.
6.  Повышение экономичности за счёт снижения расходов сырья.
7.  Оптимизация управления.
8.  Повышение безопасности.
9.  Повышение экологичности.

Информационные функции АСУТП

К информационным относятся такие функции АСУТП, результатом выполнения которых являются представление оператору системы или какому-либо внешнему получателю информации о ходе управляемого процесса

Информационные функции

1) Сбор исходной информации о технологическом процессе в виде результатов текущих измерений выходных координат объекта и состояний основных видов оборудования
![[Pasted image 20250908145704.png]]

2. Первичная обработка информации — фильтрация, устранение помех, экстраполяция (с очисткой, выбраковкой случайных данных).
![[Pasted image 20250908145918.png]]
3. Промежуточное хранение информации. Данные из подсистем АСУ ТП поступают, как правило, не одновременно, требуют взаимной проверки и увязки. 
4. Унификация информации. Данные преобразуются к принятым единицам измерения.
5. Эргономичная многоэкранная визуализация с возможностью детализации по желанию оператора и предоставление информации потребителям.
![[Pasted image 20250908150511.png]]
![[Pasted image 20250908151015.png]]![[Pasted image 20250908151128.png]]
6. Хранение информации (трендов параметров). Целью хранения данных служит накопление исторических данных
![[Pasted image 20250908151304.png]]
7. Контроль соответствия параметров процесса допустимым значениям и информирование персонала о выходе за допустимые границы – пределы сигнализации;
![[Pasted image 20250908151831.png]]
8. Информирование оператора о наступлении опасных (аварийных или предаварийных) ситуаций
![[Pasted image 20250908152428.png]]

9. Ведение журнала действий оператора
![[Pasted image 20250908152702.png]]
10. Вычисление текущих значений показателей, характеризующих качество технологического процесса, но не поддающихся непосредственному измерению
