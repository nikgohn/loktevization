# Работа в PyCharm   
- Создать проект в заранее выбранной папке, сделав соответствующие настройки   
- Все задания выполнять в этом (!!!) проекте, добавляя для каждого задания новую директорию — папку.   
- В этой папке при необходимости создавать другие папки, пакеты, скрипты (файлы Python) и другие файлы   
- уметь работать в консоли Python, командной строке из среды pyCharm   
- уметь устанавливать новые пакеты, при необходимости подключая требуемые настройки.
