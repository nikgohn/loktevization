# Лабораторная работа №2. Анализ работы замкнутой АСР
При анализе работы АСР отвечают, по существу, на 2 вопроса:
1. Обладает ли синтезированная АСР теми свойствами, которые были заложены при синтезе? (это, ну по существу, проверка: нет ли ошибок?)
2. Какими свойствами, важными для дальнейшего использования системы и которые не были заложены при синтезе, обладает система?

Рассмотрим состав и содержание отчёта.
Титульный лист по стандарту СТО: `АНАЛИЗ РАБОТЫ ЗАМКНУТОЙ АСР`
Введение – примерно 1 страница, аналогичное первому отчёту.
Во введении должна быть представлена структурная схема рассматриваемой АСР. Должно быть приведено краткое описание принципа построения и порядка работы. Должны быть приведены передаточные функции для канала регулирования объекта и регулятора
$W_{op}(p)=\frac{k}{(T_1p+1)(T_2p+1)}e^{-\tau p}$
$W_{рег}(p)=S_1+\frac{S_0}{p}$ – ПИ регулятор
, а так же значения коэффициентов ПФ объекта по каналу регулирования, значения, найденные в первой лабораторной работе, настроек регулятора $S_0$ и $S_1$, частота $w_{опт}$, соответствующая этим настройкам, значения степени колебательности $m$, при котором определены настройки (0,221) 

Раздел 1. Получение (запись) передаточных функций по рассматриваемым каналам.
Основной анализ работы АСР будем проводить по каналам, связанным с выходной координатой $x_{вых},$ по этому в дальнейшем нас будут интересовать 3 канала:
$$x_з\to x_{вых}$$
$$x_в\to x_{вых}$$
$$x_вр\to x_{вых}$$
В более общем случае (этого не надо делать ни в отчёте, ни в курсовой) могут быть интересны и другие каналы, связанные, например, с ошибкой регулирования $\Delta x$, со значением регулирующего воздействия $x_p$. По указанным каналам необходимо записать Передаточные Функции, а также аналитические выражения для изображения входной координаты.
Удобно для решения подобных задач использовать ПФ разомкнутой системы:
$$W_{pc}(p)=W_{op}(p)\cdot W_{рег}(p)=...$$
Окончательную функцию записать самостоятельно

Используя эту ПФ, ПФ по каналу задания будет равна:
$$W_{зс}^з(p)=\frac{x_{вых}(p)}{x_з(p)}=\frac{W_{рс}(p)}{1+W_p(p)}=...$$
Тоже закончить самим

Аналитическое выражения для изображения переходной функции
$$x_{вых}(p)=W_{зс}^з(p)\cdot x_з(p)=\frac{1}{p}\frac{W_{pc}(p)}{1+W_{pc}(p)}=...$$

Далее, получив аналитические выражения для изображения выходной координаты, необходимо оценить статическую ошибку в системе, а также оценить возможность и целесообразность аналитического нахождения переходной функции.
Статическую ошибку находим по теореме о конечном значении:
$$x_{вых}^{уст}=\lim\limits_{p\to0}p\cdot x_{вых}(p)=\lim\limits_{p\to0}\frac{1}{p}\frac{W_{pc}(p)}{1+W_{pc}(p)}=\frac{W_{pc}(p)}{1+W_{pc}(p)}\biggl|_{p=0}=...$$
$$\Delta x^{уст}=|x^{уст}_з-x^{уст}_{вых}|$$
Возможность и целесообразность аналитического нахождения переходной функции оценивается по виду, по структуре её изображения, или, более точно говоря, по её характеристическому уравнению, которое можно получить приравняв к нулю знаменатель соответствующих передаточных функций.
Возможны следующие варианты:
- Характеристическое уравнение не является алгебраическим. В таком случае корни аналитически найти нельзя, следовательно нельзя записать в аналитическом виде выражение для переходной функции (не можем разложить дробь на простейшие слагаемые, аналитическое выражение записать невозможно).
- Характеристическое уравнение – алгебраическое, но имеет высокий порядок (5 и более). Аналитических выражений для корней не существует, следовательно нельзя аналитически найти выражение для переходной функции.
- Характеристическое уравнение является алгебраическим третьего или четвёртого порядка. Аналитические выражения для корней существуют, следовательно можно записать аналитическое выражение для переходной функции. Однако в следствии громоздкого вида выражений для корней использовать подобную запись не целесообразно.
- Характеристическое уравнение является алгебраическим второго или меньшего порядка. В этом случае существуют простые выражения для корней, которые можно использовать для записи аналитического выражения ПФ.
Общий вывод из выше сказанного:
В большинстве случаем для объектов с запаздыванием, для объекта более чем первого порядка с ПИ-регулятором и т.д. аналитические выражения для ПФ замкнутой АСР получить либо невозможно, ли нецелесообразно, поэтому для построения переходных процессов в замкнутой АСР требуется использовать численные методы решения задач.
