# Реляционные БД
Набор простых таблиц, между которыми существуют связи (отношения) с помощью числовых кодов.
Основные понятия:
- Сущность → таблица − любой различимый объект предметной области
- Атрибут → Поле таблицы
- Связь
	- 1 - parent - первичный ключ
	- $\infty$  - child - внешний ключ
Типы отношений:
- 1−1
- > 1−$\infty$
- $\infty$−$\infty$ (физически невозможно)

#  Нормализация БД
Разработка такой структуры БД, в которой нет избыточных данных и связей.

## 1НФ (нормальная форма)
Требует чтобы таблицы БД не имели повторяющихся значений и каждое поле таблицы/ атрибут сущности было атомарным (неделимым).

| Имя и фамилия | → | Имя | Фамилия |
| ---- | ---- | ---- | ---- |
| Иван иванов | → | Иван | Иванов |
Не должно быть полей, которые означают различные виды одного и того же

## 2НФ
- Структура таблицы БД была приведена к 1НФ
- Любое поле таблицы должно зависеть только от его первичного ключа ( ключ − поле или комбинация полей, однозначно определяющая запись)
## 3НФ
- Структура БД должна быть приведена к 2НФ
- Не было транзитивных зависимостей между не ключевыми полями
	Транзитивная зависимость − не должно быть полей, которые могут быть найдены с помощью остальных.

# Язык DRL

![[20240322_161834.jpg]]
Синтаксис оператора выборки данных. Классический подход
``` SQL
SELECT [ALL | DISTINCT] <список полей выбора>
-- Используется для выбора данных из базы данных. ALL выбирает все записи, включая дубликаты. DISTINCT исключает дубликаты.

FROM <имя таблицы1>,[<имя таблицы2>, ... ]
-- Определяет таблицы, из которых будут выбираться данные.

[WHERE <условия>]
-- Указывает условия, которые должны быть выполнены для включения записей в результат.

[GROUP BY <имя поля1>, [<имя поля2>, ... ]]
-- Группирует результаты по одному или нескольким полям. Используется в сочетании с агрегатными функциями (например, COUNT, MAX).

[HAVING <условие>]
-- Условие, применяемое к группам, созданным с помощью GROUP BY, а не к отдельным записям.

[ORDER BY <имя поля1>[ASC | DESC], [<имя поля2>[ASC | DESC], ... ]]
-- Сортирует результаты запроса по одному или нескольким полям. ASC указывает на сортировку по возрастанию, DESC - по убыванию.

```

Пример
Запрос 1. Получить список всех товаров
``` SQL
SELECT TOVAR

FROM TOVARI
```
Результат:
Товар 2
Товар 3
Товар 1

Задание условия выборки. Получить список всех товаров, цена которых находится в диапазоне от 5 до 8.
1) 
``` SQL
SELECT TOVAR
FROM TOVARI
WHERE CENA>=5 AND CENA <= 8
```
Результат:
Товар 2
Товар 1

2) 
``` SQL
SELECT TOVAR
FROM TOVARI

WHERE cena BETWEEN,5 AND 8;
```

Результат:
Товар 2
Товар 1

3) 
``` SQL
SELECT TOVAR
FROM TOVARI

WHERE CENA IN (5,6,8)
```
Результат:

Товар 2

### Выборка из нескольких таблиц. С использованием WHERE

Пример. Получить информацию в следующем виде: название покупателя - купленный товар - количество. Выбрать товары, цена на которые больше 5.
``` sql
SELECT POKUPATELI.POKUPATEL, TOVARI.TOVAR,
OTPUSK.KOLICHESTVO
FROM POKUPATELI, TOVARI, OTPUSK
WHERE TOVARI.ID_TOVARA= OTPUSK.TOVARI
AND POKUPATELI.ID_POKUPATEL= OTPUSK. POKUPATELI
AND CENA >5;
```

Выборка из нескольких таблиц. С использованием JOIN. Внутреннее соединение.

``` sql
SELECT [ALL | DISTINCT] <список полей выбора>
-- Выбирает данные из базы данных. ALL возвращает все записи, включая дубликаты. DISTINCT исключает дубликаты.

FROM <имя таблицы1>
-- Определяет первую таблицу, из которой будут выбираться данные.

[INNER] JOIN <имя таблицы2>
-- Добавляет данные из второй таблицы. INNER JOIN возвращает только те записи, которые имеют совпадающие значения в обеих таблицах.

ON <условие соединения1>
-- Указывает условие, по которому происходит соединение таблиц.

[INNER] JOIN <имя таблицы3>
-- Добавляет данные из третьей таблицы. Можно добавить столько JOIN, сколько необходимо.

ON <условие соединения2>
-- Условие для соединения третьей таблицы.

...
-- Можно продолжить добавлять дополнительные JOIN с соответствующими условиями.

[WHERE <условие выборки>]
-- Условие, которое должно быть выполнено для включения записей в результат. Применяется после всех JOIN.

```

Пример. Получить информацию в следующем виде: название покупателя - купленный товар - количество. Выбрать товары, цена на которые больше 5

```sql
SELECT Pokupateli.Pokupatel, Tovari.Tovar,
Otpusk.Kolichestvo
FROM Pokupateli
JOIN Otpusk
ON Pokupateli. IdPokupatel= Otpusk.Pokupateli
JOIN Tovari
ON Tovari.IdTovara = Otpusk.Tovari
WHERE Tovari.Cena> 5;
```






# Представление
**Представление** − виртуальная таблица, которая актуализируется в результате выполнения указанного запроса на выборку данных
**Создание представлений**
``` postgreSQL
CREATE VIEW имя_представления (имя_столбца, ...)
	AS запрос
```
Хранится на сервере БД в виде запроса `SELECT` 

Пример. Создать представление, содержащее список студентов группы КИ-121.
``` postgresql
CREATE VIEW GroupKI121 (Name) AS
SELECT stName
FROM students, groups
WHERE students.grNum = groups.grNum AND
groups.grName = 'КИ-121'
```

Обращение к представлению:
``` postgresql
SELECT * FROM GroupKI121;
```


**Удаление представлений**
```postgresql
DROP
```
