# Сортировка выбором по неубыванию
Сортировка выбором – это алгоритм сортировки массива или списка путём постепенных перестановок наименьших элементов в начало списка или наибольших в конец.
- Вычислительная сложность O(n²)
- Затраты памяти O(I)
```
| Исходный массив         | 1   | -6 | -7 | 3 | 25 | -10 |
|-------------------------|-----|----|----|---|----|-----|
| Первый проход min=-10   | 1   | -6 | -7 | 3 | 25 | -10 |
|                         | -10 | -6 | -7 | 3 | 25 | 1   |
| Второй проход min=-7    | -10 | -6 | -7 | 3 | 25 | 1   |
|                         | -10 | -7 | -6 | 3 | 25 | 1   |
| третий проход min=-6    | -10 | -7 | -6 | 3 | 25 | 1   |
|                         | -10 | -7 | -6 | 3 | 25 | 1   |
| четвёртый проход min =1 | -10 | -7 | -6 | 3 | 25 | 1   |
|                         | -10 | -7 | -6 | 1 | 25 | 3   |
|  пятый проход min=3     | -10 | -7 | -6 | 1 | 25 | 3   |
|                         | -10 | -7 | -6 | 1 | 3  | 25  |

```
Упорядочение элементов массива выбором
```C++
int main()
{
	float b, max, a[20];
	int i, j, n, k, nom;
	cout<<"n=";
	cin>>n;
	cout<<"Massiv a\n";
	for(i=0;i<n;i++)
		cin>>a[i];
	k=n;
	for(j=0;j<=k-2;j++)
	{
		max=a[0];
		nom=0;
		for(i=1;i<k;i++)
		if ([i]>max)
		{
			max=a[i];
			nom=i;
		}	
		b=a[k-1];
		a[k-1]=a[nom];
		a[nom]=b;
		k--;
	}
	cout<<"Massiv a\n";
	for(i=0;i<n;i++)
		cout<<"a"<<i<<")="<<a[i]<<\t;
	cout<<endl;
}
```

# Сортировка вставками по убыванию
Сортировка вставками – алгоритм сортировки, в котором элементы входной последовательности просматриваются по одному, в каждый новый поступивший элемент размещается в подходящее место среди ранее упорядоченных элементов.
- Вычислительная сложность O(n²)
- Затраты памяти O(I)
 Рассмотрим на примере массива:
 В сортировке вставками начинаем со второго элемента.
 Проверяем между собой второй элемент с первый и, если надо, меняем местами. Сравниваем следующую пару элементов и проверяем пары до неё.
