#### Задание 2: Явная транзакция с несколькими запросами и точками восстановления

1. **Состояние таблицы до транзакции**

SELECT * FROM public.dishes WHERE dish_id IN (1, 2);


_Результат запроса, показывающий состояние таблицы `dishes` до выполнения транзакции._ (Изображение 3)

2. **Транзакция с точками восстановления и откатом**

BEGIN;

UPDATE dishes
SET cost = 850
WHERE dish_id = 2;

SAVEPOINT before_update_2;

UPDATE dishes
SET cost = 400
WHERE dish_id = 3;
ROLLBACK TO SAVEPOINT before_update_dish_2;

COMMIT;


3. **Состояние таблицы после транзакции**

```sql
SELECT * FROM public.dishes WHERE dish_id IN (1, 2);
```

#### Задание 4: Вложенная транзакция с использованием точек восстановления

1. **Состояние таблицы до транзакции**

```sql
SELECT * FROM public.ingredients;
```

_Результат запроса, показывающий состояние таблицы `ingredients` до выполнения транзакции._ (Изображение 7)

2. **Транзакция**

```sql
BEGIN;

-- Вставляем первый ингредиент
INSERT INTO public.ingredients (name, amount, units, days_to_exp)
VALUES ('Ingredient 1', 5, 'kg', 30);

-- Создание точки восстановления для вложенной транзакции
SAVEPOINT sp1;

-- Вставляем второй ингредиент (намеренно вызываем ошибку)
INSERT INTO public.ingredients (name, amount, units, days_to_exp)
VALUES ('Ingredient 2', -10, 'kg', 30);

-- Откат к точке восстановления в случае ошибки
ROLLBACK TO SAVEPOINT sp1;

-- Продолжаем транзакцию, вставляем третий ингредиент
INSERT INTO public.ingredients (name, amount, units, days_to_exp)
VALUES ('Ingredient 3', 2, 'kg', 20);

-- Фиксация изменений
COMMIT;
```

3. **Состояние таблицы после транзакции**

```sql
SELECT * FROM public.ingredients;
```

_Результат запроса, показывающий состояние таблицы `ingredients` после выполнения транзакции._ (Изображение 8)

#### Задание 5: Транзакция для добавления логически связанных данных

1. **Состояние таблиц до транзакции**

```sql
-- Состояние таблицы orders до транзакции
SELECT * FROM public.orders;

-- Состояние таблицы dishes_in_orders до транзакции
SELECT * FROM public.dishes_in_orders;
```

_Результат запросов, показывающих состояние таблиц `orders` и `dishes_in_orders` до выполнения транзакции._ (Изображение 9 и Изображение 10)

2. **Транзакция**

```sql
BEGIN;

-- Вставляем новый заказ в таблицу orders и получаем order_id
WITH new_order AS (
    INSERT INTO public.orders (client_id, cost)
    VALUES (1, 50.00)
    RETURNING order_id
)
-- Вставляем блюда в заказ, используя полученный order_id
INSERT INTO public.dishes_in_orders (order_id, dish_id, amount)
SELECT order_id, 1, 2 FROM new_order;

INSERT INTO public.dishes_in_orders (order_id, dish_id, amount)
SELECT order_id, 2, 1 FROM new_order;

-- Фиксация изменений
COMMIT;
```

3. **Состояние таблиц после транзакции**

```sql
-- Состояние таблицы orders после транзакции
SELECT * FROM public.orders;

-- Состояние таблицы dishes_in_orders после транзакции
SELECT * FROM public.dishes_in_orders;
```

_Результат запросов, показывающих состояние таблиц `orders` и `dishes_in_orders` после выполнения транзакции._ (Изображение 11 и Изображение 12)
